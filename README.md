# zarefrum — портфолио

Сайт-портфолио: https://zarefrum.github.io

Проекты:
- **Джарвис** — голосовой ассистент с локальной нейросетью (Python, Rust, Ollama, Vosk, Whisper, Piper)
- **Discord-бот circle** — статистика Dota 2, ставки, экономика, мини-игры (Python, discord.py, SQLite)
- **Пульт ПК** — управление компьютером с телефона (Python, FastAPI, PWA)
- **Лендинги** — «Угли», «ОпораСтрой», «Отвес» (HTML, CSS, JavaScript) — живые демо в папке `demo/`

- **UWU** — каталог аниме, сериалов, фильмов и игр: оценки, тир-листы, «Я и IMDb», друзья, ставки на рейтинги, магазин и профиль — `uwu/`

Сайт статический: HTML + CSS + JS, без сборки и фреймворков.
